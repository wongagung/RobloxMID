Roblox snippet

Siap ditempel ke music player kamu.

local sound = workspace.MusicPlayer.Sound

sound.SoundId = "rbxassetid://ASSET_ID"
sound.PlaybackSpeed = 0.5
sound.Volume = 1
sound.Looped = true

sound:Play()
Ganti ASSET_ID dengan ID asset Roblox.

Quick reference

Target normal 1× untuk beberapa source speed yang umum.

Formula: 1 ÷ sourceSpeed
